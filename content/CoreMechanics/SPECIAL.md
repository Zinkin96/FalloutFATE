# S.P.E.C.I.A.L.

В данной системе атрибуты **S.P.E.C.I.A.L.** определяют общий уровень развития персонажа в различных областях.

Каждый атрибут имеет числовое значение и связан с несколькими навыками. **Атрибут определяет числовое значение проверки, а навык определяет область и способ применения этого атрибута.**

## Атрибуты

| Атрибут                                                                | Связанные навыки                                    |
| ---------------------------------------------------------------------- | --------------------------------------------------- |
| [**S — Strength (Сила)**](https://chatgpt.com/c/Strength)              | Холодное оружие, Тяжёлое оружие, Запугивание        |
| [**P — Perception (Восприятие)**](https://chatgpt.com/c/Perception)    | Энергетическое оружие, Метательное оружие, Внимание |
| [**E — Endurance (Выносливость)**](https://chatgpt.com/c/Endurance)    | Выживание, Без оружия, Стойкость                    |
| [**C — Charisma (Харизма)**](https://chatgpt.com/c/Charisma)           | Красноречие, Бартер, Воля                           |
| [**I — Intelligence (Интеллект)**](https://chatgpt.com/c/Intelligence) | Медицина, Ремонт, Наука                             |
| [**A — Agility (Ловкость)**](https://chatgpt.com/c/Agility)            | Лёгкое оружие, Манёвренность, Ловкость рук          |
| [**L — Luck (Удача)**](https://chatgpt.com/c/Luck)                     | Азарт, Поиск ресурсов, Стечение обстоятельств       |

| ---------------- | -------------------: | ---------------------------------------------------------------------------------------------- |

| **+3 Хорошо**    |                    1 | Заметно выше среднего.                                                                         |

| **+1 Слабо**     |                    3 | Ниже среднего, есть заметные ограничения.                                                      |

# Атрибуты и навыки

Каждый навык связан с определённым атрибутом. Базовое значение навыка равно значению связанного с ним атрибута.

Навык определяет область применения атрибута и используется для выполнения конкретных действий.

Связь навыка с атрибутом является фиксированной и не изменяется в зависимости от ситуации.

Если персонаж хочет решить задачу другим способом, он может использовать другой подходящий навык, если его описание соответствует выполняемому действию.

Например, если у персонажа:

> **Сила +4**

то связанные с ней навыки используют значение **+4**:

- Холодное оружие +4;    
- Тяжёлое оружие +4;    
- Запугивание +4.

# Изменение атрибутов

Эффекты препаратов, Особенностей, снаряжения и другие игровые эффекты могут временно или постоянно повышать или понижать значение атрибута выше или ниже этого диапазона.

Например, персонаж с **Силой +4**, получивший **+2 к Силе** от препарата, имеет:

> **Сила +6**

## Изменение связанных навыков

Поскольку базовое значение навыка определяется связанным с ним атрибутом, изменение атрибута автоматически изменяет базовое значение всех связанных навыков.

> [!example]- Пример
> Персонаж имеет:
> 
> > **Сила +4**
> 
> Его навыки:
> 
> - Холодное оружие +4;
> - Тяжёлое оружие +4;
> - Запугивание +4.
> 
> После получения **+2 к Силе**:
> 
> > **Сила +6**
> 
> И соответственно:
> 
> - Холодное оружие +6;
> - Тяжёлое оружие +6;
> - Запугивание +6.

Когда заканчивается один эффект, удаляется только предоставленный им модификатор. Остальные действующие модификаторы сохраняются.

## Несколько эффектов

Изменения атрибута складываются между собой, если конкретное правило не указывает иное.

> [!example]- Пример
>
> > Сила +4  
> > Баффаут: +2 Силы  
> > другой эффект: +1 Силы
> 
> Итоговое значение:
> 
> > **Сила +7**

Все навыки, связанные с Силой, также получают итоговое значение **+7**.

# Выбор навыка

При совершении действия игрок описывает, **что именно делает персонаж**, после чего определяется подходящий навык.

Навык должен соответствовать способу выполнения действия.

**Игрок не выбирает атрибут отдельно от навыка.**

Например, персонаж хочет открыть запертый объект.

- Вскрывает механический замок отмычками → **Ловкость рук (Ловкость)**.    
- Взламывает электронный терминал → **Наука (Интеллект)**.    
- Ремонтирует или отключает механизм → **Ремонт (Интеллект)**.    
- Выбивает дверь силой → подходящий **навык**, связанный с **Силой**.    

Цель действия может быть одинаковой, но разные способы её достижения могут требовать разных навыков.

---

# Границы применения навыков

Связанные с атрибутом навыки описывают его основные области применения.

Это не означает, что каждый навык используется только для одного конкретного действия. Навык может применяться для разных действий, если они соответствуют его описанию.

Например, **Ловкость рук** может использоваться не только для вскрытия замков, но и для других действий, требующих точной работы руками.

А **Ремонт** может использоваться не только для починки предметов, но и для действий, связанных с устройством, настройкой или отключением механизмов.

При этом навык не может использоваться только потому, что его атрибут кажется подходящим.

Важно соответствие **самого навыка выполняемому действию**.

---

# Разные способы решения одной задачи

Одной цели можно достичь с помощью разных навыков.

Например, персонажу необходимо получить доступ внутрь закрытого помещения.

Он может:

- открыть механический замок с помощью **Ловкости рук**;    
- взломать электронную систему с помощью **Науки**;    
- починить или отключить неисправный механизм с помощью **Ремонта**;    
- уничтожить преграду с помощью подходящего боевого или физического навыка;    
- убедить охранника открыть дверь с помощью **Красноречия**.    

В каждом случае используется навык, соответствующий непосредственно выполняемому действию.

**Нельзя просто заменить навык другим навыком, потому что его связанный атрибут имеет более высокое значение.**

# Создание преимуществ

При [[CoreMechanics#Преимущество и помеха|создании преимущества]] также определяется конкретный способ, которым персонаж пытается изменить ситуацию.

Например, персонаж хочет получить преимущество перед противником.

### Внимание

Персонаж внимательно изучает окружающую обстановку и замечает:

- слабое место в позиции противника;    
- удобное укрытие;    
- приближающуюся угрозу;    
- следы или другие важные детали.    

### Наука

Персонаж анализирует устройство или технические особенности противника:

- определяет уязвимость робота;    
- понимает принцип работы турели;    
- находит слабое место механизма;    
- определяет способ отключения системы.    

### Красноречие

Персонаж воздействует на людей:

- входит в доверие;    
- убеждает союзника;    
- провоцирует противника;    
- заставляет человека раскрыть нужную информацию.    

Здесь не выбирается атрибут для создания преимущества.

**Выбирается навык, соответствующий способу создания преимущества, а атрибут определяется этим навыком.**

# Боевые примеры

В бою тот же принцип применяется при выборе навыка.

Например, персонаж хочет заставить противника отступить.

Если он угрожает противнику физической силой, используется **Запугивание (Сила)**.

Если он убеждает противника словами, используется **Красноречие (Харизма)**.

Если он пытается воздействовать на противника через анализ его поведения или уязвимости, используется соответствующий навык, если его описание позволяет совершить такое действие.

Таким образом, один и тот же результат может быть достигнут разными способами, но каждый способ использует **свой навык и связанный с ним атрибут**.

---

# Необычное применение навыка

Игрок может предложить необычное применение навыка, если описание действия соответствует его назначению.

В спорных случаях игрок должен объяснить, **почему выбранный навык подходит для описанного действия**.

Мастер определяет, соответствует ли предложенное действие описанию навыка.

При этом нельзя выбирать навык исключительно из-за высокого значения его связанного атрибута.

Например, если персонажу необходимо открыть электронный терминал, нельзя использовать **Холодное оружие (Сила)** только потому, что Сила персонажа выше Интеллекта.

Однако если персонаж пытается решить проблему с помощью физической силы — например, вырвать терминал из стены, — это уже другое действие и для него определяется соответствующий навык.

---

# Главное правило

**Сначала определяется действие и подходящий для него навык. Затем используется атрибут, связанный с этим навыком.**

Не:

> «Какой атрибут я хочу использовать?»

А:

> **«Что именно я делаю и какой навык это описывает?»**

Атрибут после этого определяется автоматически.
