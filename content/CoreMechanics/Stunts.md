# Трюки

**Трюк** — это специальная способность персонажа, которая даёт ему преимущество в определённой ситуации или позволяет действовать по правилам, отличающимся от обычных.

Трюки отражают конкретные навыки, приёмы, специализацию или необычные возможности персонажа.

Трюк должен описывать **конкретное условие и конкретный механический эффект**.

Трюки делятся на три вида:

1. **Усиление навыка**;
2. **Замена навыка**;
3. **Исключение из правила**.

При создании персонажа каждый персонаж получает возможность выбрать **по одному трюку каждого вида**.

---

# Усиление навыка

Трюк этого вида даёт **+2 к определённому навыку**, когда выполняется указанное в трюке условие.

Бонус применяется только тогда, когда условие трюка непосредственно выполняется.

Трюк не изменяет базовое значение навыка и не действует в ситуациях, которые не соответствуют его условию.

### Формат

> **Название:** +2 к **Навыку**, когда **условие**.

### Примеры

**Стрелок из укрытия**  
Получает **+2 к Лёгкому оружию**, когда атакует из укрытия и не перемещался в этом ходу.

**Мастер переговоров**  
Получает **+2 к Красноречию**, когда ведёт переговоры с одним собеседником и не участвует в непосредственном конфликте.

**Охотник на мутантов**  
Получает **+2 к Выживанию**, когда определяет свойства, следы или поведение мутантов в дикой местности.

---

# Замена навыка

Трюк этого вида позволяет использовать **один навык вместо другого**, когда выполняется указанное условие.

При этом используется обычная процедура проверки заменяемого навыка, включая его:

- значение;
- преимущества и помехи;
- аспекты;
- трюки;
- другие эффекты, которые относятся непосредственно к используемому навыку.

Трюк не даёт дополнительный бонус к навыку. Он только разрешает использовать другой навык в определённой ситуации.

### Формат

> **Название:** когда **условие**, персонаж может использовать **Навык A** вместо **Навыка B**.

### Примеры

**Уличный боец**  
Когда персонаж использует Силу для запугивания противника в непосредственной близости, он может использовать **Стойкость** вместо Запугивания.

**Оружейный эксперт**  
При попытке определить состояние, устройство или неисправность оружия персонаж может использовать **Лёгкое оружие** вместо Ремонта.

**Следопыт**  
При поиске следов конкретного человека в дикой местности персонаж может использовать **Выживание** вместо Внимания.

# Исключение из правила

Трюк этого вида позволяет персонажу **игнорировать или изменить конкретное базовое правило системы** в строго определённой ситуации.

Такой трюк должен всегда явно указывать:

1. какое правило он изменяет;
2. при каком условии действует исключение;
3. что именно происходит вместо обычной процедуры.

Трюк не может просто давать персонажу неопределённое право «делать что-то иначе».

**Исключение действует только в пределах прямо указанного правила.**

Если трюк изменяет правило действия, он не изменяет автоматически другие связанные правила.

### Формат

> **Название:** когда **условие**, персонаж может **конкретное исключение из правила**.

### Примеры

**Стремительная перезарядка**  
Персонаж может перезарядить оружие **свободным действием один раз за ход** вместо обычного основного действия.

**Двойной выстрел**  
Если персонаж использует оружие, которое обычно требует перезарядки после каждого выстрела, он может совершить **две последовательные атаки из этого оружия в один ход**, после чего оружие требует перезарядки. Обе атаки выполняются по обычным правилам.

**Неожиданный манёвр**  
Один раз за сцену персонаж может совершить перемещение между двумя соседними зонами **после завершения своего основного действия**, не тратя отдельное действие на это перемещение.

---

# Ограничения трюков

Трюк должен быть **конкретным**.

Не следует формулировать трюк как:

> «Персонаж получает +2, когда это полезно».

Или:

> «Персонаж может делать невозможные вещи».

Такая формулировка не определяет механический эффект.

Трюк не должен:

- отменять последствия любых действий;
- автоматически гарантировать успех;
- предоставлять неограниченные дополнительные действия;
- создавать бесконечный ресурс;
- позволять игнорировать любое правило по желанию игрока;
- изменять другие правила, кроме прямо указанного исключения.

Если трюк изменяет базовое правило, изменение должно быть **локальным и явно сформулированным**.

---

# Сочетание трюков

Разные трюки могут действовать одновременно, если их условия выполняются и их эффекты совместимы.

Трюки не отменяют друг друга автоматически.

Если два трюка изменяют одно и то же правило и прямо противоречат друг другу, применяется более конкретное правило, если один из трюков прямо не устанавливает иной приоритет.

Один и тот же трюк не может применяться несколько раз к одной проверке, если его описание прямо не разрешает это.

---

# Создание собственных трюков

При создании нового трюка сначала определяется его вид:

- **Усиление навыка** — если трюк должен давать +2 в конкретной ситуации;
- **Замена навыка** — если персонаж должен использовать один навык вместо другого;
- **Исключение из правила** — если трюк должен изменить конкретную базовую процедуру.

Затем необходимо определить:

1. условие применения;
2. механический эффект;
3. ограничения;
4. продолжительность или частоту применения, если они необходимы.

Чем сильнее изменение базового правила, тем уже должно быть условие его применения.
