# Предметы

Предметы представляют собой экипировку, инструменты и расходные материалы, которые помогают персонажу выполнять задачи, получать преимущества или использовать специальные эффекты.

По характеру использования предметы делятся на две категории:

- **Постоянные:** например, [[InventoryAndEquipment/Items/Tools/index#Инструменты|инструменты]], которые можно использовать многократно.
- **Одноразовые:** например, [[InventoryAndEquipment/Items/Consumables/index#Расходники|расходники]], которые исчезают или тратятся после применения.
