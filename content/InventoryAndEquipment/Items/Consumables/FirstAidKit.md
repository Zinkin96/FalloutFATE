# Аптечка первой помощи

Стандартный медицинский набор, содержащий перевязочные материалы, обезболивающие средства и инструменты для оказания первой помощи.

Аптечка предназначена для стабилизации состояния персонажа и лечения незначительных, но мешающих действовать повреждений.

**Стоимость:** 1 [[CharacterCreation#Начальные очки экипировки|очко экипировки]]

# Тип

[[InventoryAndEquipment/index#Расходники|Расходник]]

# Эффект

Позволяет лечить **лёгкие последствия**.

Для успешного лечения требуется проверка **Медицины** со сложностью **+2**.

При успешном применении **вне конфликта** персонаж полностью восстанавливает стресс.
