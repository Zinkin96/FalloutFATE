# Бронебойные патроны

Специализированные боеприпасы с усиленным сердечником, предназначенные для пробития защитных материалов.

Они позволяют эффективнее поражать защищённые цели, однако не увеличивают разрушительную силу попадания при отсутствии брони.

**Стоимость:** 1 [[CharacterCreation#Начальные очки экипировки|очко экипировки]]

# Тип

[[InventoryAndEquipment/index#Расходники|Расходник]]

# Совместимость

Используются только с оружием, использующим навык **Лёгкое оружие**.

# Эффект

**Длительность:** единоразово.

До конца текущей атаки цель не получает модификатор к **Защите Стойкостью**, предоставляемый бронёй.

Бронебойные патроны не увеличивают наносимый урон и не влияют на другие источники уменьшения получаемого урона.
