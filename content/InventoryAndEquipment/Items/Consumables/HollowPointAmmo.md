# Экспансивные патроны

Специализированные боеприпасы с изменённой конструкцией снаряда, предназначенные для увеличения повреждений при попадании.

При столкновении с целью такой боеприпас деформируется, создавая более широкую область поражения и передавая больше энергии.

**Стоимость:** 1 [[CharacterCreation#Начальные очки экипировки|очко экипировки]]

# Тип

[[InventoryAndEquipment/index#Расходники|Расходник]]

# Совместимость

Используются только с оружием, использующим навык **Лёгкое оружие**.

# Эффект

**Длительность:** единоразово.

При успешной атаке персонаж получает:
- **+1 к урону**.
