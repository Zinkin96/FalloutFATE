# Набор отмычек

Набор отмычек — комплект специализированных инструментов для вскрытия механических замков.

Включает различные приспособления для работы с запирающими механизмами и позволяет выполнять точные операции, недоступные с помощью обычных подручных средств.

**Стоимость:** 2 [[CharacterCreation#Начальная экипировка|очка экипировки]]

# Тип

[[InventoryAndEquipment/Items/Tools/index#Инструменты|Инструмент]]

# Эффект

Персонаж получает:
- **Модификатор (+1)** к проверкам **Ловкости рук**, связанным со вскрытием механических замков.

# Особенности применения

Набор отмычек не позволяет открыть любой замок автоматически.

Сложность вскрытия зависит от конструкции замка, его состояния и наличия у персонажа необходимых навыков.
