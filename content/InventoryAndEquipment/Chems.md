# Препараты

Препараты имеют три уровня эффективности:

- **Ослабленный эффект** — результат применения препарата с учётом особенности [[Chem_Resistant+|Сопротивляемость химии]].
- **Обычный эффект** — стандартное действие препарата.
- **Усиленный эффект** — результат применения препарата персонажем с особенностью [[Chem_Reliant+|Чувствительность к химии]].

После каждого применения препарата выполняются все указанные в его описании побочные эффекты и проверки привыкания с помощью навыка **[[Endurance#Выживание|Выживание]]** против указанной сложности.

Использование препаратов подходит под правила использования [[InventoryAndEquipment/index#Расходники|расходников]].

## Повторное применение

Если персонаж повторно применяет тот же препарат, **пока его эффект уже действует**:

- модификаторы от препарата не складываются;
- эффект препарата не усиливается;
- длительность действующего эффекта не увеличивается.

Повторное применение всё равно считается отдельным применением препарата. Поэтому все эффекты, связанные с самим фактом применения, срабатывают снова, включая **проверку на зависимость**, если она предусмотрена для этого препарата.

# Зависимость

Если персонаж получает эффект зависимости от препарата, негативные эффекты зависимости не действуют, пока персонаж находится под действием этого же препарата.

После окончания действия препарата эффект зависимости снова начинает влиять на персонажа.

Зависимость может быть снята следующими способами:

- лечение у квалифицированного врача;
- применение специального препарата [[Fixer|Детоксин]].

Самостоятельное преодоление зависимости без медицинской помощи невозможно.
